# Still — Public Beta v0.1

Capture effortlessly. Keep reliably. Find instantly.

A small, local Mac library with the lavender flag and a calm reader. Save text and
links, organize folders and tags, search saved text and comments, and keep selected
article snapshots offline.

Deletion is recoverable for 30 days through Recently Deleted; Undo delete restores
the most recent deletion in the current session. JSON backups preserve text,
annotations, timestamps, folders and deleted items. Imports merge without replacing
existing records. Automatic clipboard capture starts paused on every launch.

Requires macOS 14 or newer; this initial package targets Apple silicon. Expand the
ZIP and drag Still into Applications. Public packages must be Developer ID signed
and notarized before this release is published.

Known limits: no sync or global shortcut; plain text and links only; article extraction
can fail on complex or restricted websites. Source-app labels are estimates. Automatic
capture cannot reliably recognize every secret. Data and backups are not encrypted by
Still. Import is limited to 100 MB; version-3 backups require this beta or newer.
Temporary clipboard history expires separately and cannot be recovered after expiry.
Large-library performance and Intel support have not yet been verified.
